# 分镜表与提示词稿件的目录、命名与识别规则

[返回文档目录](./readme.md) · [返回项目首页](../README.md)

分镜面板（画布右侧「分镜」）只读取工作区里的固定目录与固定文件名。**目录名、文件名、JSON 字段名写错时不会报错，只会静默不显示**，因此先按本文核对结构，再排查内容。

> 新建或打开项目时，服务端会自动在工作区根目录写入一份 `README.md` 格式说明（仅在该文件不存在时写入，不会覆盖你改过的内容）。删除后下次打开项目会重新生成。

## 🗂️ 目录结构

以下路径均相对「工作区根目录」；`分镜表/`、`资产/`、`提示词/`、`生成/` 四个目录名不可改。

```text
<工作区>/
├── 分镜表/                          # 分段目录的父目录，名字固定
│   └── 第06段_导出/                 # 必须匹配 第<数字>段_导出
│       └── 分镜脚本.json            # 文件名固定，唯一被解析的分镜数据
├── 资产/                            # 素材图库；解析器只在这里找图，可无限分层
│   ├── 人物/女主-云天娇/云天娇_53-54_集.png
│   └── 场景/0808_场景4_云家后院棚.png
├── 提示词/                          # 稿件目录；解析器只在这里找 .md
│   └── 08_06b_后院棚下续_视频提示词.md
└── 生成/
    ├── 06.mp4                       # 段视频，与段号对应
    ├── 待归位/                      # 外部生成器先丢这里，服务端自动改名归位
    └── 关键帧/第06段_导出/          # 自动抽帧输出，命名 = <asset>.png
        └── 08_云天娇_53-54集.png
```

| 目录 | 必需 | 扫描方式 | 说明 |
| --- | --- | --- | --- |
| `分镜表/` | 是 | 只扫一层 | 只认 `第<数字>段_导出` 形式的子目录 |
| `资产/` | 建议 | 递归，忽略 `.` 开头的项 | 只收图片：`png jpg jpeg webp gif` |
| `提示词/` | 否 | 递归 | 只收 `.md` |
| `生成/` | 否 | 只扫一层 | 视频：`mp4 mov webm mkv m4v` |

## 📝 命名规则

| 对象 | 规则 | 合法 / 非法示例 |
| --- | --- | --- |
| 分段目录 | 正则 `^第([\d.]+)段_导出$`，数字可为小数 | `第06段_导出` ✅ `第18.5段_导出` ✅ `06_后院` ❌ `第6段` ❌ |
| 分镜 JSON | 固定名 `分镜脚本.json` | `分镜脚本.json` ✅ `分镜_06.json` ❌ |
| 段视频 | 整数段号补两位：`01.mp4`；小数保持原样：`18.5.mp4`；多版本用 `01_1.mp4`、`01_2.mp4` | `06.mp4` ✅ `6.mp4` ❌ |
| 提示词稿件 | `.md`，文件名需能认领到分段（见下） | `SC03_seedance.md` ✅ `08_06b_后院棚下续_视频提示词.md` ✅ |
| 关键帧 | 自动生成 `生成/关键帧/<段目录名>/<asset>.png`，`asset` 里的 `\ / : * ? " < > \|` 会被替换成 `_` | 无需手工创建 |

### 提示词稿件的归属判定（三档，依次放宽）

1. **文件名含场景号**：场景号取自该段 `分镜脚本.json` 里**首镜 `no` 的 `SC\d+` 前缀**（`SC03-SH155` → `SC03`）。文件名（去空格、下划线、连字符、转义反斜杠后）包含 `SC03` 即命中。
2. **正文含镜号**：文件名不带场景号时，读稿件正文，出现本段任一 `no`（如 `SC03-SH155`）即命中。**这一档让 `08_06b_…` 这类按场次命名的稿件无需改名即可挂载。**
3. **目录内仅一份 md**：以上都没命中，且 `提示词/` 递归只有一份 `.md` 时，用它。

命中多份时按 **seedance > h3/comfyui > 其他** 排序，再按自然序，依次对应 `06.mp4`、`06_1.mp4`。

## 🧾 分镜脚本.json 结构

```json
{
  "version": 1,
  "shots": [
    {
      "no": "SC03-SH155",
      "scene": "SC03 后院棚下（后段）",
      "size": "中近景",
      "angle": "平视",
      "pos": "横推位一",
      "move": "横向平移，由云天娇一侧平推到老郑",
      "lens": "50mm",
      "dur": "6",
      "visual": "横推：镜头从靠棚一侧的云天娇（虚化）横推到老郑（实焦）",
      "action": "笑着抬手朝院子方向一比划",
      "line": "老郑：都是泥腿子出身，除了种地也不会别的，",
      "sfx": "虫鸣、远处鸡叫",
      "trans": "硬切",
      "light": "傍晚金光贴地，棚下暗一档",
      "color": "暖金主调",
      "prop": "白底蓝边搪瓷碗",
      "wardrobe": "浅粉碎花衬衫",
      "vfx": "",
      "beat": "拍1",
      "risk": "横推末端易失焦",
      "asset": "08_云天娇_53-54集"
    }
  ]
}
```

`version` 可选，`shots` 必需且为数组；每镜 **20 个字段全部按字符串读取**，缺字段等于空字符串，不报错。

| 字段 | 面板标签 | 关键约束 |
| --- | --- | --- |
| `no` | 镜号 | 首镜必须以 `SC<数字>` 开头，否则场景号为空、只能靠正文认领稿件 |
| `scene` | 场景 | 时间轴按它分组统计时长与镜数 |
| `size` `angle` `pos` `move` `lens` | 景别 / 摄法 / 机位 / 运镜 / 焦段 | 仅展示 |
| `dur` | 时长 | **必须是数字字符串**（`"4.5"`、`"6"`）。用于总时长统计与关键帧抽帧时间点，非数字按 0 处理 |
| `visual` `action` `light` `color` `prop` `wardrobe` | 画面内容 / 人物动作 / 光线 / 色彩 / 道具 / 服装 | 按此顺序拼成该镜的默认图片提示词 `【视觉】…【动作】…` |
| `line` `sfx` `trans` `vfx` `beat` `risk` | 台词 / 声音 / 转场 / 特效 / 节拍 / 风险 | 仅展示 |
| `asset` | 素材 | 指向 `资产/` 里的图片（见下） |

### `asset` 与图片的匹配顺序

依次尝试，命中即止：

1. 与图片**去掉扩展名的文件名**完全一致（忽略大小写），如 `女1_王嫣` → `女1_王嫣.png`；
2. 去掉分隔符（空格、`_`、`-`）与转义反斜杠后一致；
3. 去掉开头的数字前缀后再比对，如 `08_云天娇_53-54集` → `云天娇_53-54_集.png`；
4. 同时忽略扩展名再比对一次。

## ✍️ 提示词稿件格式

### 代码块：取「含【时间轴】且最长」的那块

一份稿件可以按【风格】【主体描述】【场景环境】【时间轴】【镜头语言】分段写成多个代码块，解析器不会取第一个代码块，而是：

1. 收集全文所有 ```` ``` ```` 围栏块；
2. 优先取**含 `【时间轴】`** 的块；
3. 其中再取**最长**的一块作为「整段提示词」正文；
4. 都没有 `【时间轴】` 时退回第一个块。

因此把完整提示词放最后的「整段提示词（一次复制）」块里，会优先生效。

### 逐镜切分

正文里 `【时间轴】` 之后、下一个 `【` 之前的内容，按行首 `[镜N]` 切块：

```text
【时间轴】
[镜1]中近景，横推位一，50mm，横向平移、由云天娇一侧平推到老郑、停稳。
……（本镜描述）
[镜2]中近景，环绕位一，85mm，单向弧线环绕。
……
```

`[镜1]` 与后面的文字之间有无空格均可；切分只认 **行首 `[镜`**，写成 `镜1`、`【镜1】` 不会被切分。

### 素材清单表

表格放在代码块外（给人看），解析器按行首 `|` + 可选反引号 + `@` 或 `<` 识别，**两列起即可**：

```markdown
| 占位   | 文件名                        |
| ------ | ----------------------------- |
| @人物1 | 08/08_云天娇_53-54集.png      |
| @场景1 | 08/0808_场景4_云家后院棚.png  |
```

| 写法 | 是否识别 | 说明 |
| --- | --- | --- |
| `\| @人物1 \| 文件名 \|` | ✅ | 常用写法 |
| `\| \`@人物1\` \| 文件名 \|` | ✅ | 带反引号的 Seedance 写法 |
| `\| <Subject 1> \| 文件名 \|` | ✅ | H3 / ComfyUI 写法 |
| `12.59. 03:08` 这类非表格行 | ❌ | 不是表格行，直接忽略 |

- 只有**图片扩展名**的行会解析出路径；`.mp3` 等音色行保留名称但路径为空。
- 文件名中的 Markdown 转义（`08\_云天娇\_53-54集.png`）会先还原再匹配。
- 文件名可带目录前缀（`08/`），匹配时只取最后一段文件名。

## 🔍 常见「不显示」排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 面板提示「没有找到 分镜表/*_导出/分镜脚本.json」 | 分段目录名不对，或 JSON 不在段目录里 | 目录改为 `分镜表/第06段_导出/`，文件名为 `分镜脚本.json` |
| 有分段但没有任何提示词 | 文件名与正文都没命中镜号，且目录内有多份 md | 让文件名含场景号，或在稿件正文里写入该段镜号 |
| 提示词只显示【风格】那一小段 | 旧版只取第一个代码块，稿件前面先写了【风格】 | 已修复：现在取含【时间轴】的最长块 |
| 逐镜提示词为空 | `【时间轴】` 缺失，或用了 `镜1`/`【镜1】` 而非行首 `[镜1]` | 改为 `[镜1]` 开头 |
| 素材显示「缺图」 | 引用名与 `资产/` 里的图片名对不上，或图片放在 `素材/` | 图片放进 `资产/` 任意子目录，命名与引用一致 |
| 整段消失 | JSON 语法错误（缺逗号、全角引号） | 用 `JSON.parse` 能过的最小文件重建 |
| 段号是小数时视频找不到 | 视频名写成 `第18.5段.mp4` | 小数段号直接用 `18.5.mp4` |
